# LIVE PALETTE

Mac에서 캡처한 이미지의 주요 색상과 포인트 색상을 자동으로 모으는 작은 메뉴 막대 앱입니다.

## 다운로드

**[앱 다운로드](https://github.com/aabf088/live-palette/releases)**

릴리스의 `LIVE-PALETTE-macOS-arm64.zip`을 내려받으세요.

- macOS 14 이상
- Apple Silicon Mac (M1, M2, M3, M4 등)
- Intel Mac은 현재 지원하지 않습니다.
- 첫 공개 베타이며, Apple Developer ID 서명과 공증은 아직 적용하지 않았습니다. macOS 보안 설정에 따라 실행이 차단될 수 있습니다. [Apple의 앱 보안 안내](https://support.apple.com/ko-kr/102445)를 확인하세요.

## 설치와 사용

1. ZIP을 풀고 `LIVE PALETTE.app`을 응용 프로그램 폴더로 옮겨 실행합니다.
2. 메뉴 막대의 팔레트 아이콘으로 스크린샷 감지를 켜거나 끕니다. 처음 실행할 때는 켜져 있습니다.
3. 평소처럼 `⌘⇧3` 또는 `⌘⇧4`로 화면을 캡처합니다.
4. 주요 색상 5개가 자동 저장되고, HEX 코드 다섯 줄이 클립보드에 복사됩니다. 서식을 지원하는 앱에서는 색상 네모도 함께 붙여넣습니다.

색상 하나를 누르면 해당 색상만 한 줄로 복사합니다. 화살표를 펼치면 현재 팔레트를 제외한 최근 기록 두 개가 보입니다. 기록을 누르면 다시 불러오고 복사합니다.

메뉴 막대 아이콘이나 패널을 우클릭하면 **화면 선택 · 복사 · 팔레트 저장 · 저장한 팔레트** 메뉴를 사용할 수 있습니다. `화면 선택`은 내부 화면 분석용 선택값이며 macOS 기본 캡처 영역을 변경하지 않습니다.

## 색상 선별

이미지의 픽셀 면적과 색상 차이로 주요 색상 3개를 고르고, 색상 차이·채도·면적을 함께 고려해 포인트 색상 2개를 채웁니다. 밝은 색부터 어두운 색 순으로 표시합니다. 매우 작은 색상 영역은 잡음으로 제외될 수 있고, 원본의 색이 부족하면 같은 색을 반복합니다.

## 개인정보와 현재 제한

- 분석과 팔레트 저장은 Mac 안에서 처리합니다. 화면 이미지를 외부로 보내거나 별도로 보관하지 않습니다.
- 팔레트에는 색상, 비율, 날짜, 원본 파일 이름을 저장합니다.
- 새 스크린샷 파일과 macOS 스크린샷 미리보기를 감지합니다. 보호된 폴더 접근은 macOS의 허용이 필요할 수 있습니다.
- Control 키를 함께 눌러 클립보드에만 보내는 캡처는 지원을 보장하지 않습니다.
- 스크린샷 저장 상황에 따라 감지가 몇 초 늦을 수 있습니다.
- 감지가 켜져 있으면 캡처 후 클립보드가 색상 값으로 바뀝니다.
